Tipos de Variáveis em Python com input()

int (Inteiro)

Converte texto para número inteiro.

Exemplos:
int("7") → 7
int("-4") → -4
int("0") → 0
int("123") → 123
float (Ponto flutuante)
Converte texto para número com casas decimais.
Exemplos:
float("4.5") → 4.5
float("0.75") → 0.75
float("-2.3") → -2.3
float("0.0") → 0.0
bool (Booleano)
Converte texto para True ou False.
Exemplos:
bool("True") → True
bool("False") → False
bool("0") → True (porque é uma string não vazia)
bool("") → False (string vazia é False)
str (String)
Converte qualquer dado para texto.
Exemplos:
str(5) → "5"
str(3.14) → "3.14"
str(True) → "True"
str("Olá") → "Olá"
